HUS-CLEAN (RUST) — COMMANDES POUR PUBLIER SUR GITHUB
======================================================

Deja fait pour toi dans ce dossier (rien a refaire) :
  - git init
  - git add -A
  - git commit -m "..."
  - git branch -M main

Le dossier /home/user/hus-clean-rust est donc deja un depot git local,
avec un seul commit propre contenant exactement :
  hus-clean.exe, LICENSE, README.md, "Procedure Hus-Clean.pdf", src/

Il ne reste que les commandes suivantes a lancer TOI-MEME (elles touchent
a ton depot GitHub distant, donc je ne les execute pas a ta place).
Lance-les depuis un terminal, dans ce dossier :

  cd /home/user/hus-clean-rust


1) Relier ce depot local a ton depot GitHub existant
------------------------------------------------------
Remplace l'URL si besoin (adapte a ton token / methode d'authentification
deja geree de ton cote — HTTPS avec PAT, ou SSH) :

  git remote add origin https://github.com/Spellskite-coding/hus-clean.git

  (si tu utilises un token en HTTPS, tu peux aussi faire :
   git remote add origin https://<TON_TOKEN>@github.com/Spellskite-coding/hus-clean.git
   ou laisser le gestionnaire d'identifiants Git te demander le token
   au moment du push)


2) Ecraser completement la branche main distante avec ce nouveau contenu
---------------------------------------------------------------------------
Ceci supprime TOUT l'historique et le contenu actuels de la branche main
sur GitHub (release/, release.zip, src.zip, ancien code C++...) et les
remplace integralement par ce commit unique et propre :

  git push --force origin main


3) Verification
------------------
  git remote -v
  git log --oneline

Et va jeter un oeil sur https://github.com/Spellskite-coding/hus-clean
pour confirmer que main contient bien : hus-clean.exe, LICENSE,
README.md, Procedure Hus-Clean.pdf, src/


ATTENTION
-----------
- L'etape 2 est irreversible cote GitHub (l'ancien historique de main est
  perdu, sauf si quelqu'un a un clone local de l'ancienne version).
- Si le depot a des branches protegees ou des Pull Requests ouverts sur
  main, le force-push peut etre refuse ou les casser : verifie avant.
- Les autres branches/tags existants (tags "Release Hus-Clean v1.1" etc.)
  ne sont pas touches par ces commandes, seule la branche main l'est.
